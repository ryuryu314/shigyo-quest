# 士業ドパミンクエスト（骨子版）

司法試験予備試験・公認会計士試験・司法書士試験・弁理士試験の「本試験の流れ」をステージにした、非公式の学習ゲームです。ブラウザだけで動き、ログインは不要です。

**遊ぶ:** https://ryuryu314.github.io/shigyo-quest/

- 検索エンジンには載せない設定（`<meta name="robots" content="noindex,nofollow,noarchive">`）にしています。
- 学習記録・設定は、その端末のブラウザの中（localStorage）にだけ保存されます。外部通信・広告はありません。
- iPhone の Safari で開き、共有メニューの「ホーム画面に追加」を選ぶとアプリのように起動できます。

## 本試験ロード

| 試験 | ステージ | 判定（本番の基準をもとに再現） |
| --- | --- | --- |
| 司法試験予備試験 | 短答式 → 論文式 → 口述 | 短答 159/270、論文 240/500、口述 119（令和7年） |
| 公認会計士試験 | 短答式 → 論文式 | 短答 70%基準・40%足切り、論文 52%基準・40%足切り。短答合格は2年免除 |
| 司法書士試験 | 筆記（択一＋記述） → 口述 | 基準点 78・72・70 ＋ 合格点 255/350（令和7年）。筆記合格は次回免除 |
| 弁理士試験 | 短答式 → 論文式（必須） → 口述 | 短答 39/60・科目40%、論文 平均54・47点未満なし、口述 C評価2科目未満。短答・論文は2年免除 |

- **短答・択一**: 本番の形式（5肢択一・組合せ・個数問題・各肢の正誤・計算）。
- **論文・記述**: 答案を書く代わりに「論点 → 規範 → 結論」や「登記の目的 → 原因 → 添付情報 → 登録免許税」を選んで、答案用紙に骨組みを書き込む形式。
- **口述**: 試験官の質問に答える。間違えると副査が助け舟（その後の正解は半分の評価）。

## 解き方（簿記ドパミンクエストの本番模試モードに合わせた仕様）

- 制限時間・カウントダウンはありません。かかった時間（一時停止中は数えない）を結果に出します。
- 画面の下に固定したマークシートで番号を選び、「次へ進む」で答え合わせをして次の問題へ。スクロールせずに解答・移動できます。直前の問題の正誤と正解は、次の問題の上に小さく残ります。
- 「解答を見る」で、PC幅では問題の隣、スマホ幅では問題の下に解答が出たままになります。その問題に戻ると再び表示されます。解答を見た問題は学習記録・XPに入らず、本試験モードではその挑戦が参考記録になります（ロードは進みません）。
- どの問題にも小学生向けの「かんたんに言うと」をいつも表示します。
- 「中断」を押すか、2分間操作がないと一時停止します。解答はこのブラウザに保存され、ホームの「続きを解く」から再開できます。

## ファイル構成

```
index.html            読み込み順: core → data → store → engine → fx → game
style.css             見た目
js/core.js            名前空間 SQ、問題の登録関数、正解の導出、データ検証
js/engine.js          採点、本試験の合否判定、ロードの進行（免除を含む）
js/store.js           記録（localStorage）、レベル・称号
js/fx.js              効果音・粒子・バナー・ハンコ・XPゲージ・読み上げ
js/game.js            画面と進行
data/exams.js         4試験の段階・採点区分・配点・合格ライン
data/q-*.js           問題（試験ごと）
data/easy.js          「かんたんに言うと」（問題の id ごと）
tools/test.html       ロジックとデータの自動チェック
```

## 問題の追加方法

`data/q-*.js` に追記し、同じ `id` で `data/easy.js` に「かんたんに言うと」（答えが分かる書き方はしない）を1つ足します。`id` は成績や中断データの保存に使うので、公開後は変えないでください。追加したら `tools/test.html` を開いて、データの検証がすべて通ることを確認します（`index.html?check` でも、問題があれば画面下に一覧が出ます）。

### 択一（短答・筆記の択一）

```js
SQ.mcq('試験/段階/採点区分', {
  id: 'yobi-minpo-03', title: '答えが分からない短い題名', lv: 1〜3, form: 'combo',
  q: '問題文',
  st: [['ア', '記述', true or false, '解説（根拠条文・判例）'], ...],
  combos: ['アイ', 'アウ', ...]   // form: 'combo' のとき
});
```

- `form`: `one`（want に当たる記述を1つ選ぶ）／`combo`（組合せ）／`count`（個数）／`tf`（各記述の正誤）／`pick`（`choices` と `answer` を直接書く。計算問題など）
- `want: false` にすると「誤っているもの」を問う問題になります。
- 正解の番号は記述の正誤から自動で決まり、ちょうど1つに定まらないとデータ検証でエラーになります。

### 論文・記述

```js
SQ.kase('試験/段階/採点区分', {
  id, title, lv, facts: '事案', ask: '設問',
  steps: [{ label: '論点', type: 'multi' or 'one', pts: 20, prompt: '…', options: [['選択肢', true/false, '解説'], ...] }, ...],
  model: '答案の骨子'
});
```

### 口述

```js
SQ.oral('試験/段階/採点区分', {
  id, title, lv, intro: '主査「…」', facts: '事例',
  turns: [{ q: '主査「…」', options: [['答え', true/false], ...], hint: '副査「…」', e: '解説' }, ...]
});
```
