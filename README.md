# 士業ドパミンクエスト（骨子版）

司法試験予備試験・公認会計士試験・司法書士試験・弁理士試験の「本試験の流れ」をステージにした、非公式の学習ゲームです。ブラウザだけで動き、ログインは不要です。

**遊ぶ:** https://ryuryu314.github.io/shigyo-quest/

- 検索エンジンには載せない設定（`<meta name="robots" content="noindex,nofollow,noarchive">`）にしています。
- 学習記録・設定は、その端末のブラウザの中（localStorage）にだけ保存されます。外部通信・広告はありません。
- iPhone の Safari で開き、共有メニューの「ホーム画面に追加」を選ぶとアプリのように起動できます。

## 本番の形式（令和8年の公式の問題冊子・答案用紙・受験案内をもとに再現）

| 試験 | 時限（本番の試験時間） | 問題冊子の書き方 | 答案用紙 | 1問の配点 |
| --- | --- | --- | --- | --- |
| 予備試験 短答 | 民法・商法・民訴 1時間30分 → 憲法・行政法 1時間 → 刑法・刑訴 1時間 → 一般教養 1時間30分 | ［民法］〔第1問〕（配点：2）…（解答欄は、［No.1］）。冊子ごとに第1問から。各記述の正誤は記述ごとに解答欄 | 時限ごとのマークシート。一般教養は選択欄＋解答欄（44題中20題、超えたら番号の小さい方から採点） | 2点・3点、一般教養3点 |
| 会計士 短答 | 企業法 9:30〜10:20 → 管理会計論 11:15〜12:30 → 監査論 13:45〜14:35 → 財務会計論 15:30〜18:00 | 問題1 …一つ選びなさい。（5点）。ア〜エの組合せは1〜6。理論が先・計算が後 | 問題1〜 ①〜⑥ | 企業法・監査論5点、管理会計論 理論5点・計算6点、財務会計論6点（一部5点） |
| 司法書士 筆記 | 午前の部 9:30〜11:30 → 午後の部 13:00〜16:00 | 第1問 …**判例の趣旨に照らし正しいもの**の組合せは、後記1から5までのうち、どれか。記述式は第36問・第37問 | 択一は第1問〜 ①〜⑤。記述式は第1欄の表（登記の目的・申請事項等・添付情報・登録免許税）、添付情報は記号で | 択一3点、記述式70点 |
| 弁理士 短答 | 3時間30分 | 【特許・実用新案】1 …次のうち、正しいものは、どれか。／次の(イ)〜(ホ)のうち、…いくつあるか。（1つ〜5つ） | 科目＋番号 ①〜⑤ | 1点 |

- 本試験モードは時限ごとに表紙（注意事項・本番の試験時間）から始まり、次の時限へ進むと前の時限の答案は回収されて戻れません。
- 収録問題は本番より少ないので、問題番号・解答欄番号は収録問題の通し番号です（本番の範囲は表紙に書いています）。合否は「収録問題の得点率 × 本番の配点」で判定し、本番どおりの点数で数えた素点も結果に出します。
- 予備試験の論文式は令和8年からCBT（パソコンで入力。1頁23行・1行30字・各科目4頁）。本アプリは選んで組み立てる形式です。
- 時刻を載せているのは公式資料で確かめられた会計士・司法書士だけで、予備試験・弁理士は試験時間の長さだけを表示しています。

- **短答・択一**: 本番の形式（5肢択一・組合せ・○×の組合せ（1〜8）・個数問題・各記述の正誤・計算）。
- **論文・記述**: 答案を書く代わりに「論点 → 規範 → 結論」や「登記の目的 → 原因 → 添付情報 → 登録免許税」を選んで、答案用紙に骨組みを書き込む形式。
- **口述**: 試験官の質問に答える。間違えると副査が助け舟（その後の正解は半分の評価）。

## 解き方（簿記ドパミンクエストの本番模試モードに合わせた仕様）

- 制限時間・カウントダウンはありません。かかった時間（一時停止中・表紙を読んでいる間は数えない）を、結果画面で時限ごとに本番の試験時間・1問あたりの目安と比べます。
- 画面の下に固定した答案用紙（マークシート）で番号を塗り、「次へ進む」で答え合わせをして次の問題へ。スクロールせずに解答・移動できます。直前の問題の正誤と正解は、次の問題の上に小さく残ります。
- 「解答を見る」で、PC幅では問題の隣、スマホ幅では問題の下に解答が出ます。「解答を閉じる」を押すまで、次の問題以降も解答を出したままにします（開閉はこのブラウザが覚え、設定からも切り替えられます）。解答を見た問題は学習記録・XPに入らず、本試験モードではその挑戦が参考記録になります（ロードは進みません）。
- どの問題にも小学生向けの「かんたんに言うと」をいつも表示します。
- 「中断」を押すか、2分間操作がないと一時停止します。解答はこのブラウザに保存され、ホームの「続きを解く」から再開できます。

## ファイル構成

```
index.html            読み込み順: core → data → store → engine → fx → game
style.css             見た目
js/core.js            名前空間 SQ、問題の登録関数、正解の導出、データ検証
js/engine.js          採点、本試験の合否判定、ロードの進行（免除を含む）
js/store.js           記録（localStorage）、レベル・称号
js/fx.js              効果音・粒子・バナー・ハンコ・XPゲージ・読み上げ
js/game.js            画面と進行
data/exams.js         4試験の段階・採点区分・配点・合格ライン
data/q-*.js           問題（試験ごと）
data/easy.js          「かんたんに言うと」（問題の id ごと）
tools/test.html       ロジックとデータの自動チェック
```

## 問題の追加方法

`data/q-*.js` に追記し、同じ `id` で `data/easy.js` に「かんたんに言うと」（答えが分かる書き方はしない）を1つ足します。`id` は成績や中断データの保存に使うので、公開後は変えないでください。追加したら `tools/test.html` を開いて、データの検証がすべて通ることを確認します（`index.html?check` でも、問題があれば画面下に一覧が出ます）。

### 択一（短答・筆記の択一）

```js
SQ.mcq('試験/段階/採点区分', {
  id: 'yobi-minpo-03', title: '答えが分からない短い題名', lv: 1〜3, form: 'combo',
  q: '問題文',
  st: [['ア', '記述', true or false, '解説（根拠条文・判例）'], ...],
  combos: ['アイ', 'アウ', ...]   // form: 'combo' のとき
});
```

- `form`: `one`（want に当たる記述を1つ選ぶ）／`combo`（組合せ）／`count`（個数）／`tf`（各記述の正誤。解答欄は記述ごと）／`ox`（正しいものに○・誤っているものに×の組合せを1〜8から。記述は3つ）／`pick`（`choices` と `answer` を直接書く。計算問題など）
- `want: false` にすると「誤っているもの」を問う問題になります。
- 正解の番号は記述の正誤から自動で決まり、ちょうど1つに定まらないとデータ検証でエラーになります。
- 1問の配点 `pts` は省略すると本番の付け方になります（js/engine.js の `SQ.ptsOf`）。問題番号・解答欄番号・「（解答欄は、［No.1］）」「（5点）」は画面側で付けるので、問題文には書きません。
- `subj` は表示用の科目名（司法書士の午前の部の「民法」、一般教養の「英語」など）。
- 会計士の管理会計論・財務会計論は、本番どおり理論問題（`pick` 以外）が先、計算問題（`pick`）が後に並びます。

### 論文・記述

```js
SQ.kase('試験/段階/採点区分', {
  id, title, lv, facts: '事案', ask: '設問',
  steps: [{ label: '論点', type: 'multi' or 'one', pts: 20, prompt: '…', options: [['選択肢', true/false, '解説'], ...] }, ...],
  model: '答案の骨子'
});
```

- 司法書士の記述式は `no: 36`（不動産登記）・`no: 37`（商業登記）を書き、答案用紙の欄名が手順名と違うときは手順に `row: '上記以外の申請事項等'` のように書きます。`multi` の手順の選択肢は【添付情報一覧】の記号（ア・イ・ウ…）で表示します。

### 口述

```js
SQ.oral('試験/段階/採点区分', {
  id, title, lv, intro: '主査「…」', facts: '事例',
  turns: [{ q: '主査「…」', options: [['答え', true/false], ...], hint: '副査「…」', e: '解説' }, ...]
});
```
